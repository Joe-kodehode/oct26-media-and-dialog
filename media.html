HTML Media

HTML lets us add images, video, audio, and other media to a webpage.

Video

We use the <video> tag to add a video.

The controls attribute adds play, pause, volume, and fullscreen buttons.

Useful video attributes

Videos can use extra attributes to change how they behave.

Common attributes:

  • controls = show video controls
  • autoplay = starts video on page load
  • loop = repeats the video
  • muted = starts with no sound
  • poster = image shown before video plays

Audio

We use the <audio> tag to add sound or music.

Useful audio attributes

Audio uses many of the same attributes as video.

Common attributes:

  • controls = show audio controls
  • autoplay = starts on page load
  • loop = repeats the audio
  • muted = starts with no sound

Iframe

We use the <iframe> tag to embed another webpage or video inside our page.

Important iframe attributes

Iframes often need extra attributes to work well.

Common attributes:

  • src = sets the source
  • title = description for accessibility
  • allowfullscreen = lets the video go fullscreen
  • width and height = set the size of the iframe
